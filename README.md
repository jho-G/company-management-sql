# Company Management Database (SQL)

A relational database system designed using MySQL to manage companies,
employees, products, customers, suppliers, and orders.

## Features
- Fully normalized relational schema
- Primary and foreign key constraints
- Views for simplified data access
- Stored procedures for common operations
- Transactions for data consistency
- Role-based access control

## Technologies
- MySQL

## How to Run
1. Execute `schema.sql`
2. Execute other SQL files as needed
